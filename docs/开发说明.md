# 随译源代码

主程序使用 C# 5、WPF、.NET Framework 4.8，无第三方运行依赖。

## 编译

在源码目录运行：

```powershell
./build.ps1
```

输出为 `bin/LingoFloat.exe` 和配置文件。也可使用 `./build.ps1 -OutputDir ./release`。

编译脚本使用 Windows .NET Framework 自带的 `csc.exe`，不要求额外安装 .NET SDK。图标已经提供；可选的 `create_icon.py` 用 Pillow 重新生成图标，仅开发时需要 Python 和 Pillow。

## 文件

- `Core.cs`：地址校验、两种 API 协议、SSE 解析、取消、加密、缓存与用量。
- `App.cs`：WPF 控件事件、设置窗口、全局快捷键、启动入口。
- `Main.xaml` / `Settings.xaml`：可编辑原生界面。
- `app.ico` / `app.manifest` / `LingoFloat.exe.config`：图标与 Windows 运行配置。
- `Tests.cs` / `UiTests.cs`：核心和 WPF 集成检查。
- `mock_server.py`：只绑定回环地址的模拟接口；无外网调用，不需要真实 API 密钥。

## 测试

先运行模拟接口（Python 标准库）：

```powershell
python -u ./mock_server.py --port-file ./port.txt
```

另一个终端读取端口后运行：

```powershell
$fixturePort = Get-Content -LiteralPath ./port.txt -Raw
./test.ps1 -Endpoint ("http://127.0.0.1:" + $fixturePort + "/v1") -DataDir ./test-data
./test-ui.ps1 -Endpoint ("http://127.0.0.1:" + $fixturePort + "/v1") -DataDir ./ui-test-data
```

每次测试使用新的 DataDir，避免已有缓存和用量影响断言。先执行 build.ps1 创建 bin 目录。界面测试会渲染 PNG 并短暂打开设置对话框，使用的都是模拟密钥和本地接口。测试全局快捷键时，若 Ctrl+Alt+T 已被其他实例或程序占用，验证的是清晰的不可用提示。

1.1 交付前通过 60 项核心检查和 29 项界面检查。另在用户授权下验证了真实 Cline API。用户密钥和个人配置不包含在源码或便携包中。

模型目录：通用 OpenAI 兼容接口使用 /models；ClinePass 模式使用 /ai/cline/recommended-models 的 clinePass 分组。模型列出状态与实际验证状态分开保存；刷新不会把新模型直接标为可用。非流式响应支持 Cline 的 success/data 包装。部分 Cline 模型强制思考，关闭思考参数只对已验证兼容的模型发送。

## API 参考

- [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)
- [OpenAI 流式输出](https://developers.openai.com/api/docs/guides/streaming-responses)

Chat 默认使用 max_completion_tokens，兼容服务商可在设置中改为 max_tokens 或省略。没有重试时自动降级机制，以避免意外重复产生付费请求。Responses 通过 max_output_tokens 限制输出，并设置 store=false。
