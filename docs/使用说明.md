# 随译 · Lingo Float 1.1

一个用于阅读外文文档的 Windows 桌面翻译窗口。

## ClinePass 配置

填写自己的 Cline API 地址、密钥和模型 ID。使用订阅模型时勾选「仅显示 ClinePass 订阅模型」。程序会将密钥加密保存在当前 Windows 用户的数据目录，仓库不包含个人配置。

## 切换与检查模型

- 在主窗口上方的下拉框选择模型，选择会自动保存，下一次翻译使用新模型。切换本身不发起翻译请求。
- 点击「刷新」重新读取模型目录。列表刷新不生成模型文本；新条目显示「未验证」，不会被当作已经测试成功。
- 设置中也可以读取列表，或手动输入完整模型 ID。点击「测试当前模型」发送一次 Hello 的短翻译，会产生少量用量并计入应用统计。
- ClinePass 默认勾选「仅显示 ClinePass 订阅模型」，使用专门订阅目录。Cline 的通用目录包含按量计费模型，不能据此判断是否包含在订阅内。
- 「在支持的模型上关闭思考」已为实测兼容的 MiniMax M3.1 Flash、MiMo V2.6 Flash 启用。GLM 5.3 Flash 强制思考，保持其默认行为。未知 Cline 模型也保持默认行为，避免因为关闭思考参数而调用失败。

## 开始使用

1. 解压便携包，将 `LingoFloat.exe` 和 `LingoFloat.exe.config` 放在同一文件夹，双击 `LingoFloat.exe`。
2. 点击右上角「设置」，填写自己的 API 地址、API 密钥和模型名称，然后保存。
3. 复制需要翻译的内容，粘贴到原文框。默认停止输入 0.8 秒后自动翻译。

程序在 Windows 10/11、.NET Framework 4.8 环境运行。无需安装 Python、Node 或浏览器扩展；本机已完成编译与测试。

## API 怎么填

- **API 地址**：填写服务商的基础地址，通常包含版本路径，例如 `https://api.openai.com/v1`。也可直接粘贴以 `/chat/completions` 或 `/responses` 结尾的完整接口地址，程序会按所选协议生成请求路径。
- **API 密钥**：填写服务商提供的密钥，不是网站登录密码。
- **模型名称**：填写完整模型 ID，不是展示名称。建议先选择响应快、价格低的文本模型。
- **接口协议**：大多数 OpenAI 兼容接口选择 `Chat Completions`；如果服务商要求 `/responses`，选择 `Responses`。

保存设置不会调用 API，也不会验证余额或模型权限。可点击「读取模型列表」或「测试当前模型」检查配置。

如果兼容服务商提示参数错误：展开「高级选项与缓存」，将输出参数改为 `max_tokens`；如果提示不支持 `stream_options`，取消「请求流式 token 用量」。只有在服务商确实不支持两种输出上限参数时，才选择「不发送」，此时输出量由服务商控制。

目前支持带 Bearer 密钥的 Chat Completions / Responses 接口。其他鉴权协议、Azure 特定部署路径等未适配。远程地址使用 HTTPS，本机服务可使用 `http://localhost:端口/v1`。

## 阅读时怎么用

| 操作 | 方法 |
| --- | --- |
| 自动翻译 | 勾选「自动翻译」，粘贴或输入后等待 0.8 秒 |
| 手动翻译 | 取消自动翻译，按 `Ctrl+Enter` 或点击「翻译」 |
| 快速查询剪贴板 | 先复制原文，再按 `Ctrl+Alt+T`；会呼出窗口并翻译 |
| 停止接收 | 点击「停止」或按 `Esc` |
| 切换置顶 | 勾选或取消左上角「置顶」 |
| 复制结果 | 点击结果区右上角「复制」 |

默认「自动识别」会将单个拉丁字母单词按查词处理，显示原形、英美音标、词性和简短中文释义；短语、句子和段落直接译成中文。也可在右下角切换「单词查词」或「直接翻译」。当前目标语言固定为简体中文。

每次最多输入 6000 字符，长文请分段。PDF 复制的断词、连字符和多余换行可能影响结果。第一版没有 OCR、自动抓取页面、发音或词典服务；音标与释义由所选模型生成。

关闭主窗口会退出程序，最小化后仍可用全局快捷键呼出。如果提示快捷键已被占用，可直接点击任务栏里的窗口继续使用。

## Token 与缓存

- 窗口待机不调用模型；翻译请求只包含简短规则和当前文本，不发送查询历史。
- 边生成边显示；原文改变会停止接收旧请求，旧结果不会覆盖新查询。
- 默认请求输出上限为 4096 token，单词查词请求最多 512。上限不是固定消耗，实际按模型生成量或订阅额度规则计算；参数的执行规则以服务商为准，思考 token 也可能计入用量。
- 完整结果最多缓存 200 条。相同文本、模式、模型与地址再次查询，可直接命中缓存。更换账号、模型或相关设置可能使已有条目不再命中。
- 达到输出上限或连接异常的结果不会写入缓存。重复同一查询会使用缓存；想重新请求模型，可先在设置中清空缓存。
- 用量面板统计应用记录的输入、输出 token 和缺失用量的请求次数，不估算价格，也不读取整个 Cline 账户的历史用量。外部客户端产生的请求不计入应用内的历史统计。失败、取消或接口未返回用量的请求可能消耗额度，以服务商记录为准。
- 「停止」会断开本地接收，服务商可能仍继续生成或计费。自动翻译会在每次输入停顿后触发，若希望严格控制请求次数，可使用手动模式。

## 本机数据

默认数据目录为 `%LOCALAPPDATA%\LingoFloat`：

- `settings.json`：界面/API 设置，密钥部分通过 Windows DPAPI 加密。
- `cache.dat`：使用 Windows DPAPI 加密的本地翻译缓存。
- `usage.json`：仅保存次数、日期和 token 数值。

不保存明文密钥，不记录请求日志，不自动读取剪贴板或整份文档。你主动粘贴或按快捷键提交的原文会发送到所配置的服务商。Responses 请求使用 `store:false`；服务商自身的数据保留政策仍由该服务商决定。

密钥和缓存绑定当前 Windows 用户。复制程序到另一台电脑后，需要重新填入 API 密钥。关闭缓存并保存会清空已有缓存，也可单独点击「清空缓存」。

可用 `LingoFloat.exe --data-dir "指定目录"` 将设置、缓存和用量保存在自选文件夹；同一数据目录只允许一个实例运行。

## 常见问题

- **401**：检查密钥是否有效。
- **404**：检查地址、协议和完整模型 ID。
- **400**：检查兼容参数，参考上面的输出参数与流式用量选项。
- **429 / 402**：检查余额、配额或请求频率。
- **等待超时**：检查网络和系统代理，或尝试响应更快的模型。请求总等待上限为 65 秒。
- **没有正文/结果被截断**：尝试提高输出上限、换用适合翻译的模型，或分段翻译。
